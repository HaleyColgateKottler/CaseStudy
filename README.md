Latent Proxy Variable Method Case Study Code

Haley Colgate Kottler, Amy Cochran

An analysis of the effect of hospitalization in older adults presenting to the 
emergency department (ED) with chest pain. This analysis uses the data from 
MIMIC-iv, available at https://mimic.mit.edu/docs/iv/

For a clean example of our technique, see the file 'latentVariableMethod.R'

Comparison methods can be found in 'IPW.R', 'linear.R', 'unadjusted.R', and 
'proximal.R'. Data cleaning and variable selection are in 'cleanMIMIC.R' and 
'variableSelection.R'.
